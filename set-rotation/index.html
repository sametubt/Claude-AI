How to read it · อ่านอย่างไร

RS-Ratio
ความแข็งแกร่งของกลุ่มเทียบตลาด ปรับให้ค่ากลาง = 100 Above 100 = outperforming the benchmark trend.
RS-Momentum
อัตราการเปลี่ยนแปลงของ RS-Ratio — บอกว่าความแข็งแกร่งกำลังเร่งขึ้นหรือชะลอลง Above 100 = that strength is still accelerating.
↗ Leading · นำตลาด
แข็งแกร่งกว่าตลาดและยังมีโมเมนตัมหนุน Strong and still gaining.
↘ Weakening · อ่อนแรง
ยังแข็งแกร่งกว่าตลาด แต่โมเมนตัมเริ่มแผ่ว มักเป็นจุดเริ่มของการหมุนออก Still strong, losing momentum.
↙ Lagging · ล้าหลัง
อ่อนแอกว่าตลาดและโมเมนตัมยังลบ Weak and still falling behind.
↖ Improving · ฟื้นตัว
ยังอ่อนแอกว่าตลาด แต่โมเมนตัมกลับมาเป็นบวก มักเป็นจุดเริ่มของการหมุนเข้า Weak but turning up.
Rotation · การหมุน
ตามทฤษฎี กลุ่มมักหมุนตามเข็มนาฬิกา ฟื้นตัว → นำตลาด → อ่อนแรง → ล้าหลัง Rotation is typically clockwise, but not guaranteed.
Tail · หาง
เส้นหางคือเส้นทางของกลุ่มในช่วงก่อนหน้า ยิ่งหางยาวและตรง ยิ่งเป็นแนวโน้มที่ชัด Longer, straighter tails = a more persistent move.
